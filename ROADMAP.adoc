== Risks and Mitigation

=== Risk 1: IDE Build Complexity

**Risk:** ReScript + Deno + Vite integration may have issues

**Mitigation:**
- Test build early (Phase 2)
- Have fallback: Node.js/npm if Deno fails
- Document build issues and workarounds

=== Risk 2: Idris2 Expertise

**Risk:** Formal verification requires specialized knowledge

**Mitigation:**
- Phase 4 is optional (not blocking 1.0)
- Recruit Idris2 expert consultant if needed
- Start with simpler proofs, build up

=== Risk 3: Student Confusion

**Risk:** Paradoxes may frustrate rather than educate

**Mitigation:**
- Alpha testing (Phase 7) catches this early
- Iterative design based on feedback
- Progressive difficulty (easy → hard paradoxes)
- Clear tutorials and hints

=== Risk 4: Browser Performance

**Risk:** Real-time stability tracking may be slow

**Mitigation:**
- Debounce updates (max 10 updates/second)
- WASM compiler for better performance
- Optimize rendering (virtual DOM, memoization)
- Limit example program size (≤200 lines)

=== Risk 5: Maintenance Burden

**Risk:** Three projects (Lang, DB, Struct) may be unsustainable

**Mitigation:**
- Focus on Error-Lang first (prove concept)
- Error-DB/Struct only if Lang succeeds
- Shared codebase (stability tracker, Five Whys)
- Community contributions (open source)
