== Integration 1: cadre-tea-router

=== Why?
Client-side routing for multi-panel IDE without page reloads.

=== Routes

```rescript
// Routes.res

type route =
  | Home
  | Editor({file: option<string>})
  | Explorer({layer: layer})
  | Analyzer({mode: analysisMode})
  | Documentation({page: string})

let routes = [
  ("/", Home),
  ("/edit", Editor({file: None})),
  ("/edit/:file", Editor({file: Some(param)})),
  ("/explore/:layer", Explorer({layer: parseLayer(param)})),
  ("/analyze/:mode", Analyzer({mode: parseMode(param)})),
  ("/docs/:page", Documentation({page: param})),
]

// Integration with cadre-tea-router
module Router = CadreTeaRouter.Make({
  type route = route
  let routes = routes
  let routeToPath = routeToPath
  let pathToRoute = pathToRoute
})
```

== Integration 2: draig-ssg

=== Why?
Build Error-Lang Studio as a **static site** - deployable to GitHub Pages, no server needed!

=== Architecture

```
Source (ReScript-TEA app)
  ↓ compile with ReScript
JavaScript bundle
  ↓ build with Vite
Static assets (HTML, JS, CSS)
  ↓ enhance with draig-ssg
Optimized static site
  ↓ deploy to
GitHub Pages / CDN
```

=== draig-ssg Configuration

```scheme
;; draig.scm

(site
  (name "Error-Lang Studio")
  (url "https://hyperpolymath.github.io/error-lang")

  (pages
    ((path "/")
     (template "index.html")
     (data "examples/examples.json"))

    ((path "/explore/:layer")
     (template "explore.html")
     (dynamic true))

    ((path "/docs/:page")
     (template "docs.html")
     (source "docs/*.adoc")))

  (assets
    ((source "ide/dist")
     (dest "/")))

  (build
    ((command "cd ide && npm run build")
     (output "ide/dist"))))
```

=== Benefits
- ✅ No server required (pure static)
- ✅ CDN-deployable (fast global access)
- ✅ Works offline (PWA potential)
- ✅ GitHub Pages hosting (free)

== Integration 3: proven (Idris2 Formal Verification)

=== Why?
**The compiler core should be formally verified** - especially the stability calculator and paradox detector.

=== Formally Verified Components

==== 1. Stability Score Calculation

```idris
-- proven/src/Stability.idr

||| Stability score is always in range [0, 100]
data StabilityScore : Type where
  MkScore : (n : Nat) -> {auto 0 prf : n <= 100} -> StabilityScore

||| Calculate stability with proof of correctness
calculateStability : List StabilityFactor -> StabilityScore
calculateStability factors =
  let base = 100
      penalties = sum (map impact factors)
      result = base - penalties
      clamped = clamp 0 100 result  -- Provably in range!
  in MkScore clamped {prf = clampProof}

||| Proof: Stability calculation never overflows
stabilityBounds : (factors : List StabilityFactor) ->
                  let score = calculateStability factors
                  in 0 <= score <= 100
```

==== 2. Scope Leakage Rules

```idris
-- proven/src/Scope.idr

||| Scope leakage rules with formal proof
data ScopeRule : Type where
  PrimeRun : (run : Nat) -> IsPrime run -> ScopeRule
  Palindrome : (name : String) -> IsPalindrome name -> ScopeRule
  Fibonacci : (line : Nat) -> IsFibonacci line -> ScopeRule

||| Proof: Scope leaks iff one of the rules applies
scopeShouldLeak : (run : Nat) -> (name : String) -> (line : Nat) -> Bool
scopeShouldLeak run name line =
  isPrime run || isPalindrome name || isFibonacci line

||| Proof: Scope leakage is deterministic
scopeLeakageDeterministic :
  (run1 run2 : Nat) -> (name1 name2 : String) -> (line1 line2 : Nat) ->
  run1 = run2 -> name1 = name2 -> line1 = line2 ->
  scopeShouldLeak run1 name1 line1 = scopeShouldLeak run2 name2 line2
```

==== 3. Type Collapse Correctness

```idris
-- proven/src/TypeCollapse.idr

||| Quantum type with proof of non-empty possibilities
data QuantumType : Type where
  MkQuantum : (types : Vect (S n) Type) -> QuantumType

||| Type collapse is always valid (picks from possibilities)
collapseType : QuantumType -> ObservationContext -> Nat -> Type
collapseType (MkQuantum types) ctx seed =
  let hash = (hashContext ctx + seed) `mod` length types
  in index hash types  -- Proof: index is in bounds!

||| Proof: Collapsed type is always from original possibilities
collapseCorrectness :
  (qt : QuantumType) -> (ctx : ObservationContext) -> (seed : Nat) ->
  elem (collapseType qt ctx seed) (getPossibilities qt) = True
```

== Integration 4: a2ml (Aspect Modeling)

=== Why?
Describe language aspects (positional semantics, scope leakage, etc.) declaratively.

=== Aspect Definitions

```a2ml
-- aspects/positional-operators.a2ml

aspect PositionalOperatorSemantics {
  description: "Operators change behavior based on file position"

  pointcut: BinaryExpression(operator: "+")

  advice: {
    type: around
    layer: semantics

    behavior(ast, context):
      let line = ast.location.line
      let col = ast.location.column
      let hash = (line * 31 + col) mod 4

      match hash {
        0 -> Addition(ast.left, ast.right)
        1 -> Concatenation(ast.left, ast.right)
        2 -> Subtraction(ast.left, ast.right)
        3 -> Xor(ast.left, ast.right)
      }
  }

  metadata: {
    pedagogical_purpose: "Show context affects semantics"
    real_world_parallel: "Operator overloading based on types"
    discovery_condition: "Use '+' at different columns"
  }
}
```

```a2ml
-- aspects/scope-leakage.a2ml

aspect TemporalScopeLeakage {
  description: "Variables leak from blocks on prime-numbered runs"

  pointcut: VariableAccess(scope: outer)

  advice: {
    type: around
    layer: semantics

    condition(context):
      isPrime(context.runNumber) ||
      isPalindrome(context.variableName) ||
      isFibonacci(context.declarationLine)

    behavior(ast, context):
      if condition(context) then
        AllowAccess(ast.variable)  -- Leak!
      else
        ThrowError("Variable not in scope")
      end
  }

  metadata: {
    pedagogical_purpose: "Show scope is convention, not law"
    real_world_parallel: "JavaScript var hoisting"
    discovery_condition: "Run program multiple times"
  }
}
```

=== Benefits

✅ **Declarative paradoxes**: Aspects describe behavior clearly
✅ **Modular design**: Each paradox is separate aspect
✅ **Educational metadata**: Built into aspect definitions
✅ **Runtime modification**: Can enable/disable aspects for teaching
